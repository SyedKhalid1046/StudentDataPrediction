1. Executive Summary & Problem Formulation

EduPredict addresses early identification of students at risk of academic failure. The platform solves three core predictive tasks using educational, demographic, and behavioral features:

  • Continuous Grade Prediction (Regression): Predicts final exam score (scale 0–100 and 0–20 Portuguese scale).
  • Binary Pass / Fail Classification: Predicts whether a student meets the 60.0 passing threshold with calibrated probability.
  • Academic Performance Tier Categorization (Multi-Class): Categorizes students into 4 tiers: At Risk (<55), Satisfactory (55–69), Good (70–84), and Excellent (85–100).

3. Detailed Breakdown of Regression Algorithms

Best Model Selected
1. Lasso Regression (L1-Regularization)
Type: Regularized Linear Model Hyperparameters: alpha=0.05 R² = 0.9216 | RMSE = 3.31
Loss Function: min_w { (1/2n) ||y - Xw||²₂ + α ||w||₁ }

Lasso (Least Absolute Shrinkage and Selection Operator) applies an L1 norm penalty to feature weights.

Why this algorithm is used in EduPredict:

  • Automatic Feature Sparsity: Drives non-influential feature coefficients to exact zero, isolating pure academic drivers.
  • Superior Generalization: Outperformed deep and complex ensemble models on unseen test sets by avoiding variance explosion.
  • Complete Institutional Interpretability: Allows educators to clearly understand the exact contribution of each factor.
2. Ridge Regression (L2-Regularization / Tikhonov)
Type: Regularized Linear Model Hyperparameters: alpha=1.0 R² = 0.9212 | RMSE = 3.32
Loss Function: min_w { ||y - Xw||²₂ + α ||w||²₂ }

Why this algorithm is used in EduPredict:

  • Multicollinearity Resolution: Educational variables (attendance vs absences, study time vs study efficiency) exhibit high correlation. Ridge stabilizes the matrix inversion (XᵀX + αI)⁻¹.
3. Support Vector Regressor (SVR with RBF Kernel)
Type: Kernel Support Vector Machine Hyperparameters: C=3.0, epsilon=0.15, kernel='rbf' R² = 0.9145 | RMSE = 3.46
Kernel: K(x, x') = exp(-γ ||x - x'||²) | Loss: max(0, |y - f(x)| - ε)

Why this algorithm is used in EduPredict:

  • Noise Invariance: The ε-tube ignores minor grading discrepancies within ±0.15 normalized units.
  • Non-Linear Boundary Mapping: Projects student features into infinite-dimensional Hilbert space to discover non-linear grade relationships.
4. LightGBM & XGBoost Regressors
Type: Gradient Boosted Decision Trees Hyperparameters: n_estimators=150, lr=0.07, max_depth=4 R² = 0.9082 / 0.9041

Why this algorithm is used in EduPredict:

  • Interaction Capture: Automatically learns complex non-linear feature interactions (e.g. high study time mitigating lack of internet access).
  • High-Speed Real-Time Inference: LightGBM's histogram binning enables sub-millisecond predictions on the Flask server.
5. Random Forest & Gradient Boosting Regressors
Type: Tree Ensembles (Bagging & Boosting) Hyperparameters: n_estimators=150, max_depth=10 R² = 0.8974 / 0.9023

Why this algorithm is used in EduPredict:

  • Ensemble Diversity: Random Forest reduces variance via bootstrap sampling; Gradient Boosting minimizes residuals stage-by-stage.
6. Multi-Layer Perceptron (MLP Regressor) & Decision Tree
Type: Feedforward Neural Network / CART Tree Hyperparameters: (64, 32) hidden layers, ReLU, Adam R² = 0.8860 / 0.8240

5. Data Preprocessing, Validation & Feature Engineering Algorithms

1. Stratified 5-Fold Cross-Validation Algorithm

Splits dataset into 5 balanced partitions preserving the exact distribution of student outcome tiers. Prevents sampling bias and data leakage.

2. StandardScaler (Z-Score Normalization)
z = (x - μ) / σ

Normalizes wide numerical ranges (attendance 40–100%, study time 1–30 hrs, absences 0–35) so gradient-based and distance-based models (Logistic Regression, SVR, MLP) converge effectively without feature scale dominance.

3. One-Hot Encoding Algorithm

Converts nominal attributes (parental education, tutoring, internet access, health) into binary vectors without imposing false ordinal bias.

4. Schema Auto-Mapping Algorithm (Levenshtein Fuzzy Matcher)

Implemented in SchemaAutoMapper to dynamically align arbitrary uploaded CSV column headers (e.g. "stud_time", "study_hrs") to canonical pipeline features.

5. Academic Risk Index & Study Efficiency Formulation
Academic Risk = max(0, (85-att)*1.5) + min(30, abs*2) + (fail*20) + max(0, (7-study)*3) + max(0, (65-prev)*1.2)

Synthesizes multiple warning signals into a unified institutional metric (0–100) that powers the real-time triage tags in the web dashboard.

6. Prescriptive AI Pedagogical Rule Engine

Converts model predictions into personalized, human-actionable recommendations (attendance targets, study hour increments, tutoring contracts, and enrichment pathways).
